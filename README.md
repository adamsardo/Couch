# Couch

A warm, voice-first iOS 26 app for psychology students to practise simulated therapy sessions and walk away with structured feedback. **Practice therapy before it counts.**

## What's in V1

- Onboarding (welcome → safety framing → quick profile → friction prompt → scenario recommendation → mic permission)
- One launch scenario — **Marcus**, a 28-year-old in his first session — backed by an ElevenLabs Conversational AI agent
- Voice-first session via the [ElevenLabs Swift SDK](https://github.com/elevenlabs/elevenlabs-swift-sdk), with a text fallback if the mic is denied
- Freeze-recovery prompts to help users when they go blank
- Mandatory structured debrief: 3 strengths · 3 next moves · 1 micro-drill · confidence checkpoint, generated by OpenAI's Responses API with strict structured output
- Home with the next-rep CTA, today's suggestion, last micro-focus, recent highlights, and streak
- A one-time post-debrief "aha moment" card that mirrors the user's stated friction back with it removed
- Local-only persistence via SwiftData — no accounts, no backend in V1

## Architecture

```
Couch/
  App/                 entry + AppRoot routing
  Branding/            warm Liquid Glass palette + glass card style + haptics
  Components/          shared Glass Card, PrimaryButton, SpeakingOrb, SectionTitle
  Models/              SwiftData @Model classes (UserProfile, Scenario, Session, Turn, Debrief, MicroDrill, StreakEvent)
  Persistence/         ModelContainer + SeedData + @ModelActor TranscriptStore
  Scenarios/           static catalog (Marcus blueprint)
  Services/            ElevenLabsClient, OpenAIClient (Responses API + json_schema),
                       DebriefService, TranscriptAssembler, MicPermissionService,
                       KeychainService, SecretsProvider, RapportEstimator
  Features/
    Onboarding/        OnboardingState + 6 step views
    Session/           SessionCoordinator + ConversationView + Transcript + FreezeHelpSheet
    Debrief/           DebriefCoordinator + non-dismissable DebriefGateFlow
    Home/              HomeView + Resume / Suggestion / MicroFocus / Highlights / Streak / AhaMoment cards
  Utilities/           OSLog categories + time formatting
```

Concurrency posture: coordinators are `@MainActor @Observable`, network and disk services are actors / `@ModelActor`, and only `Sendable` value types ever cross isolation boundaries (mostly through `PersistentIdentifier`).

## Local setup

### 1. Open the project

```sh
open Couch.xcodeproj
```

Xcode will resolve SPM dependencies (ElevenLabs, LiveKit, swift-protobuf, etc.) on first open. The ElevenLabs SDK is pinned to `2.0.0+`.

### 2. Configure secrets

Copy `Couch/Secrets.plist.example` to `Couch/Secrets.plist` (gitignored) and fill in:

| Key | Where to get it |
|-----|-----------------|
| `OPENAI_API_KEY` | <https://platform.openai.com/api-keys> — used for the post-session debrief |
| `MARCUS_AGENT_ID` | The agent ID from <https://elevenlabs.io/app/conversational-ai> for the Marcus persona (set as a **public** agent so the app can connect without a backend) |

Then add `Couch/Secrets.plist` to the **Couch** app target in Xcode (drag into the Project Navigator and tick the Couch target). The app reads it at launch via `SecretsProvider`, with a Keychain fallback for the OpenAI key.

Alternatively, define `OPENAI_API_KEY` and `MARCUS_AGENT_ID` as scheme environment variables for ad-hoc local runs.

> **V1 only.** Storing the OpenAI key on-device is fine for dev and TestFlight but **not** for App Store distribution. The plan leaves a `ConversationAuthProvider` hook so you can swap to a signed-URL backend later without touching the session UI.

### 3. Configure the Marcus agent in ElevenLabs

Use the system prompt from [`docs/couch_persona_sys_prompt.md`](docs/couch_persona_sys_prompt.md). Set the agent to **public** in the dashboard so the app can connect using the agent ID alone.

### 4. Build and run

```sh
xcodebuild -project Couch.xcodeproj -scheme Couch -destination 'generic/platform=iOS Simulator' build
```

Or just hit ⌘R in Xcode against any iOS 26.2 simulator.

### 5. Tests

Swift Testing unit tests + XCTest UI smoke tests are wired into the Couch scheme. Run with ⌘U or:

```sh
xcodebuild -project Couch.xcodeproj -scheme Couch \
  -destination 'platform=iOS Simulator,name=iPhone 17' \
  -only-testing:CouchTests test
```

## Branding

A warm, non-clinical palette grounded in iOS 26 Liquid Glass with `#available`-gated fallbacks for older runtimes. See [`Couch/Branding/Theme.swift`](Couch/Branding/Theme.swift) and [`Couch/Branding/GlassStyle.swift`](Couch/Branding/GlassStyle.swift).

## Out of scope for V1

Accounts, paywall, supervisor / cohort features, CloudKit sync, multi-scenario catalog beyond Marcus.
